# AGENTS.md

## Проект

Это статическое веб-приложение для расчета смен и выплат самозанятым исполнителям. Основной файл: `index.html`.

## Правила работы

- Сохранять поддержку русского текста и UTF-8.
- Не удалять юридические шаблоны договора, акта и ТЗ без явного запроса пользователя.
- Не коммитить secret key, service_role key, пароли и персональные документы.
- Для Supabase использовать только publishable/anon public key на клиенте.
- После изменений проверять: загрузку приложения, расчет недельных сумм, вкладку проверки, экспорт DOC/PDF и синхронизацию состояния.
- Если меняется схема Supabase, обновлять `supabase-schema.sql` и `README.md`.
