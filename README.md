# Расчет самозанятых

Веб-приложение для учета смен, недельных выплат, реквизитов, договоров, актов и ТЗ.

## Сайт

Рабочий адрес: https://raschetsam.vercel.app/

Без авторизации данные не показываются. После регистрации новый пользователь тоже не видит рабочие разделы, пока администратор не назначит доступ.

## Supabase

- Project URL: `https://mpsopvezhguzkkhvjnwy.supabase.co`
- В браузере используется только publishable key.
- Рабочие данные хранятся в общей таблице `public.workspace_states`.
- Права пользователей хранятся в `public.user_access`.
- Старую таблицу `public.app_states` схема сохраняет только для миграции старой персональной копии.

## Первичная настройка Supabase

1. Откройте Supabase Dashboard.
2. Перейдите в SQL Editor.
3. Выполните файл `supabase-schema.sql`.
4. В Authentication включите Email/Password.
5. В Authentication -> URL Configuration укажите Site URL: `https://raschetsam.vercel.app/`.
6. Добавьте этот же адрес в Redirect URLs.

После выполнения SQL пользователь `amankz2015@gmail.com` получает права администратора. Если такого пользователя еще нет, права будут назначены автоматически после его регистрации.

## Уровни доступа

Администратор может назначать доступ к разделам:

- Смены по месяцам
- Свод по неделям
- Реквизиты
- Документы
- Проверка
- Лог
- Администрирование

Новые пользователи создаются без доступа к данным и разделам.

## Безопасность

Не публикуйте `service_role` key, secret key, пароли, приватные документы и локальные бэкапы в репозитории. В GitHub должны лежать только рабочие файлы приложения и публичная SQL-схема.
